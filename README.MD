# Виджет банковских операций клиента.

## Описание:

В данном файле представлен список банковских операций. При помощи функции filter_by_state мы можем отфильтровать наш список, статус берем 
"EXECUTED". Вызвать можно вот так print(filter_by_state(transactions)) и к нам вернется новый список.
Так же у нас реализована функция sort_by_date, с ее помощью мы делаем сортировку списка по дате. Вызвать можно вот так 
print(sort_by_date(transactions)), сортировка по умолчанию - убывание.
